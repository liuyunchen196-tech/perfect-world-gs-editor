# tasks.data（任务数据）结构与指南

来源：155 教程《★工具篇——任务编辑器-单人FB》+ 138 端文件实测。

## 文件位置
- 服务端：`pwserver/gamed/config/tasks.data`（138 国服约 40MB）
- 客户端：`element/data/tasks.data`
- 另有 `gamed/config/task_open_beta/tasks.data`（beta 任务）

## 任务编辑器用法（第三方工具，供了解字段语义）
- 打开客户端 `element/tasks.data`。
- 搜索任务：按名称或 ID（如 轮回殿 24835）。
- 单人FB 修改：取消【组队接受】/【组队最小数】勾选（数值：0单人/1双人/2即3人/5即6人）。任务前提【组队/比较变量/势力/国王→组队接受→取消勾选】。
- 改后客户端+服务端必须同步，否则游戏内无法接取 NPC 任务。

## 与 element.data 的关联（二转/礼盒流程，教程）
- 物品类目【70 任务卷轴/71 物品奖牌】指向任务编辑器任务 ID；任务奖励又含物品 ID（EL 编辑器可查）。
- 例：挚情礼盒（物品ID 34960 关联任务）→ 任务编辑器查 34960 → 一堆商品 ID → 做二转物品包。

## 自研工具现状（如实记录）
- **tasks.data 二进制格式/加密未逆向**（教程只用第三方任务编辑器，无解析代码参考；服务端 tasks.data 可能同样加密，需分析）。
- 138 国服 tasks.data 头部需探测确认是否同 element.data 加密体系。
- 游戏内添加技能/物品/背包优先用 DEBUG 命令（见 debug-commands.md），不依赖 tasks.data 改写。
