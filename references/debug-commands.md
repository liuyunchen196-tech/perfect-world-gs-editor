# DEBUG 命令：游戏内添加技能/物品/背包

来源：155 教程《★单机篇——DEBUG命令 相关代码》。用于登录后游戏内直接添加物品/背包/仓库、改元气等。

## 开启 Debug 控制台

1. 启动游戏（客户端根目录 `启动游戏.bat`）。
2. 角色进入游戏后按 **Shift + ~** 进入命令控制台（退出按 Esc）。
3. `debug_command_mode = active` 激活（部分端默认开）。

## 常用命令（输入格式：`d_c2scmd 编号 参数`）

### 物品 / 背包 / 仓库
| 命令 | 作用 |
|---|---|
| `d_c2scmd 2001 物品ID` | 包裹添加**限时300秒**物品 |
| `d_c2scmd 3022 物品ID` | 包裹添加**一组**物品（叠加上限） |
| `d_c2scmd 10800 物品ID 数量` | **掉落/添加无时间限制**物品（ID与数量间不带空格：`10800 15314 100` 物品ID 100 个） |
| `d_c2scmd 10807 物品ID` | 仓库增加物品 |
| `d_c2scmd 2016 数值` | 扩充包裹（背包格子） |
| `d_c2scmd 10853` | 清除包裹所有物品 |
| `d_c2scmd 10854` | 清除仓库密码 |

### 角色 / 属性
| 命令 | 作用 |
|---|---|
| `d_c2scmd 1988` | 包裹增加金币（数值=当前等级×1000000） |
| `d_c2scmd 1989 数值` | 修真级别（8大乘/22天仙/32魔尊） |
| `d_c2scmd 1991 数值` | **元气上限**（0-399） |
| `d_c2scmd 2000` | 获得升级经验+当前等级×10000元神 |
| `d_c2scmd 10850 数值` | 设定声望值 |
| `d_c2scmd 10852` | 显示角色各类ID |
| `d_c2scmd 10869 状态ID` | 获得各类状态图标 |
| `d_c2scmd 10874` | 增加当前等级经验至最大 |

### 怪物 / 传送 / 帮派
| 命令 | 作用 |
|---|---|
| `d_c2scmd 10802 怪物ID 1 0 0` | 生成怪物（如 `10802 16 201 0 0` 刷201只青蚨） |
| `d_c2scmd 8900 地图ID` | 传送至地图 |
| `d_c2scmd 8888 1 x y z` | 传送坐标 |
| `d_c2scmd 3000 名称` | 建立帮派 |
| `d_delcmd 205 数值` | 获取元宝 |
| `d_c2scmd 10855 10855` | 杀死地图所有怪物并获得经验 |

### 显示 / 其它
`d_showid`（显示ID）、`d_showpos`（坐标）、`d_npcid`（NPC ID）、`d_fps`、`d_query 名称`（查ID）、`d_goto x y`（大地图移动）、`d_settimeofday`（游戏时间）。

## 补充（教程另记）
- `additem 0 $n $name 3661`：不确定的添加物品格式（3661 为物品ID示例）。
- `d_c2scmd 2002 物品ID`：销毁物品。
- 技能添加：游戏内无直接加技能命令，**技能靠 gs 修改**（见 SKILL.md 主流程）。物品 ID 需从 element.data / items.json 查询。

## 说明
- 命令仅单机/测试有效；物品 ID 从 element.data 定义，先查 ID 再发命令。
- 用 `d_c2scmd 10800` 可批量刷无时间限制物品（配合物品 ID 列表实现一键背包添加）。
